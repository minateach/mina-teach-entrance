      File processing

      • Readable text is extracted page by page; the original file remains available to its owner.
      • Scanned PDFs and image-only text are not OCR-indexed; the page is marked accordingly.
      • PDF embedded images, diagrams, and chart pixels are not automatically interpreted.
      • Exact duplicate files are detected by checksum and are not stored twice.
      • Deleting a file also removes its searchable passages.
